## TypeScript Source & Build Rules (Apply to Every Step)

- Write all application code, scripts, workers, validators, and tests in `.ts`; use `.tsx` only for React Email templates containing JSX. Do not create handwritten `src/server.js`, `src/app.js`, or JavaScript feature modules.
- **Source entry:** `backend/src/server.ts`. Development runs `npm run dev` (`tsx watch src/server.ts`). **Production entry:** `backend/dist/server.js`, generated by `npm run build` and run by `npm start`. The `.js` production filename is compiled output, not a JavaScript source-code requirement; do not replace it with `node dist/server.ts`.
- With backend ESM `NodeNext`, relative imports in TypeScript source use the emitted `.js` extension, for example `import { app } from './app.js'` resolves to source `app.ts` while compiling and to `dist/app.js` at runtime. Do not rename the source file to `.js` or enable `allowImportingTsExtensions` for this emitting build.
- Keep `strict: true`, `noImplicitAny: true`, `allowJs: false`, and `noEmitOnError: true`. Use `unknown` plus runtime narrowing for untrusted input and caught errors; avoid explicit `any`, `@ts-ignore`, and unchecked casts used to bypass validation.
- Keep request DTOs, response DTOs, API envelopes, error codes, and state unions typed and aligned with `API-Spec.md`. Serialize MongoDB `Decimal128` amounts/FX as decimal strings and dates as ISO strings at the HTTP boundary; TypeScript types do not replace Zod/runtime validation.
- Use a separate `tsconfig.test.json` extending the production config with `rootDir: "."`, `noEmit: true`, and includes for `src/**/*.ts`, `src/**/*.tsx`, `tests/**/*.ts`, and typed test configuration. Override inherited excludes to exclude only `node_modules` and `dist`. Keep tests out of production output and typecheck them explicitly.
- JSON configuration, static assets, generated build files, and tooling configurations that require JavaScript remain valid exceptions. Never commit generated `dist/` output as handwritten source.
- These source/build rules apply even when an individual step prompt is copied on its own.

     - **#24 `POST /v1/admin/auth/logout`** (`ADMIN_AUTH`): Revoke current session, clear `medaxis_admin_session` cookie, log audit event.

3. **`adminAuth.ts` Guard Middleware:**
   - Extract `medaxis_admin_session`, hash with SHA-256, check `admin_sessions` (`revoked_at: null`, `expires_at > now` — never rely on Mongo TTL cleanup delay).

4. **Strict Security Check:** Verify plaintext passwords, TOTP secrets, backup codes, and session tokens are never logged or returned after issuance.
